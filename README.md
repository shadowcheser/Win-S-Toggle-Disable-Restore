# Win+S Toggle — отключение и восстановление Win+S

[English](README.en.md) | [Русский](README.md)

Набор BAT-скриптов для Windows 10 и Windows 11, позволяющий отключить сочетание клавиш `Win + S` и при необходимости восстановить его работу.

## Возможности

- **Отключение Win + S** — добавляет клавишу `S` в параметр `DisabledHotkeys` реестра Windows.
- **Резервное копирование настроек** — сохраняет исходное состояние параметра перед изменением.
- **Восстановление настроек** — возвращает исходное значение или удаляет параметр, если до запуска скрипта он отсутствовал.
- **Автоматический перезапуск Проводника Windows** — применяет изменения без необходимости вручную перезагружать компьютер.
- **Без установки** — достаточно запустить нужный BAT-файл.

## Использование

### Отключение Win + S

1. Запусти `Disable_Win_S.bat`.
2. Дождись завершения выполнения скрипта.
3. Проверь работу сочетания клавиш `Win + S`.

### Восстановление Win + S

1. Запусти `Restore_Win_S.bat`.
2. Дождись завершения выполнения скрипта.
3. Проверь работу сочетания клавиш `Win + S`.

Для восстановления необходимо предварительно выполнить скрипт отключения, чтобы исходные настройки были сохранены.

## Как это работает

Скрипты используют PowerShell для изменения параметров реестра текущего пользователя Windows:

`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced`

Перед отключением сочетания клавиш скрипт сохраняет исходное состояние параметра `DisabledHotkeys` в резервных значениях реестра.

При восстановлении исходное значение возвращается. Если параметр `DisabledHotkeys` отсутствовал до изменения, он удаляется.

После изменения настроек скрипт автоматически перезапускает `explorer.exe`, чтобы применить изменения.

## Важные замечания

- Скрипты изменяют настройки только текущего пользователя Windows.
- Ручное редактирование реестра не требуется.
- Обычно запуск от имени администратора не нужен.
- При перезапуске Проводника панель задач и окна Проводника могут кратковременно исчезнуть и появиться снова.
- Резервная копия хранится в реестре, а не в отдельном файле.
- Не удаляй резервные значения реестра до завершения восстановления.
- Если резервная копия отсутствует, скрипт восстановления не изменяет настройки.
